# 姿势识别游戏 / Pose Detection Game

一个基于网页的姿势识别游戏，使用 MediaPipe 实现实时姿势检测。玩家可以通过身体姿势来控制游戏角色。

A web-based exercise game, using MediaPipe for real-time pose detection. The player can control the virtual avatar through their pose.

## 如何开始 / Instructions to Run

1. 克隆仓库

   Clone repository
2. 使用任意 HTTP 服务器运行项目（例如 VS Code 的 Live Server）

   Use any HTTP server to run (such as VS Code's Live Server)
3. 在浏览器中打开游戏

   Open the game in a browser
4. 允许摄像头访问权限

   Enable the webcam
5. 开始游戏！

   Start the game!

## 技术栈 / Technology Stack

- HTML5
- CSS3
- JavaScript
- MediaPipe Pose Detection

## 注意事项 / Important Notes

- 需要使用支持 WebRTC 的现代浏览器

  Need to use a browser that supports WebRTC
- 需要摄像头权限

  Need to enable webcam permission
- 建议使用 HTTPS 连接以确保摄像头正常工作

  Recommended to use HTTPS connection to ensure the webcam works as usual
